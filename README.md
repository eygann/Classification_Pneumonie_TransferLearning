# Classification_Pneumonie_TransferLearning

Dans cet exercice, nous avons utilisé réseau de neuronnes à convolution à 16 couches pré-entraîné (VGG16) afin de classer des cas de radiologie thoraciques afin de déterminer des cas de pneumonies et des cas sains, afin d'assister les radiologues dans le diagnostic de la pneumonie.
Le but de ce projet est d'utiliser le **Transfer Learning** afin d'obtenir des résultats utilisable en production par une clinique, un hôpital ou un institut de santé.
